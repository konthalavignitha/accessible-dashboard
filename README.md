
# Accessible Dashboard

## Project Description
A responsive dashboard built using semantic HTML5 and accessible components.

## Features
- Semantic HTML elements: header, nav, aside, main, section, article, and footer.
- Accessible navigation and keyboard focus indicators.
- Student data table with clear headings.
- Contact form with labels and validation.
- Modal dialog with open and close buttons.
- Responsive layout for mobile devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
To demonstrate accessible web design and improve usability for all users.
